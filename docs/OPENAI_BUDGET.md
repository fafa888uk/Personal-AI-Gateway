# OpenAI 官方费用限制 — 两层做法

> Codex 自动执行任务可能连续发大量请求，本地预算只是第二道防线。
> 务必同时在 OpenAI 官方后台设置项目硬性费用限制。

## 第一层：OpenAI 官方后台（用户必须亲自设置）

1. 登录 OpenAI 官方后台（platform.openai.com），进入所用项目的
   Billing / Limits 设置。
2. 为本项目（与网关 `OPENAI_API_KEY` 同一项目凭证）设置硬性费用上限：
   - 每月硬性上限（hard limit）：按用户预算填写。
   - 用量告警阈值：建议设为上限的 50% 与 80% 两档。
3. 核实方法：设置完成后截图或在后台确认上限数值与告警邮箱；
   本文档的“官方后台设置方法”须在真实密钥与后台访问就绪后，
   按官方最新界面逐项核实更新（不得凭记忆写死路径）。
4. 状态：**待核实**——真实密钥未到位，官方后台路径尚未逐项验证。

## 第二层：网关本地预算（硬停，默认保守值）

见 `.env.example`：

| 预算 | 默认值 | 到达后行为 |
|---|---|---|
| `BUDGET_GLOBAL_DAILY_USD` | 5 | 拒绝新请求，明确错误 + 告警 |
| `BUDGET_GLOBAL_MONTHLY_USD` | 50 | 同上 |
| `BUDGET_CLIENT_MONTHLY_USD` | 20 | 同上（按客户端） |

- 费用按上游实际返回 usage 计；上游未返回精确 usage 时标记为
  未获取/估算，绝不显示为精确用量；价格未配置时显示“价格未配置”。
- 预算调整记入审计事件；默认值等用户定数字后再改。
