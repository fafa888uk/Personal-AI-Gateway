# Personal AI Gateway — 实施计划

执行顺序按用户 2026-11-14 定的五条优先级（见 `docs/ARCHITECTURE.md` §2）：
**B 网关 → C Codex 真实端到端 → D 网页聊天先求功能可用 → E 管理后台 →
F 安全与备份 → G 集成测试 → H 独立服务器部署；视觉精修放到最后。**

| 阶段 | 内容 | 验收 | 状态 |
|---|---|---|---|
| A | 环境检查、项目初始化、架构文档 | 本文档 + `ARCHITECTURE.md` + 初始提交 | 进行中 |
| B | 核心 API 网关：`/v1/models`、`/v1/responses`、`/v1/chat/completions`、Responses 查询/取消/压缩（按 Codex 实际需求）、鉴权、模型权限、速率限制、预算硬停、SSE 透传、追踪 ID、Mock 上游 pytest | Mock 上游测试全绿；真实上游测试标记为阻塞 | 已完成（见 STATUS.md） |
| C | Codex 兼容：真实 Codex CLI 端到端工具调用、VS Code 配置指南 | 真实 Codex 测试通过（需真实密钥，阻塞中） | 阻塞（等密钥） |
| D | 网页聊天：功能可用优先，PWA（可添加到主屏幕、离线壳、自动更新）第一版交付；Flutter 客户端（聊天/模型切换/设置 + 版本信息接口）在网关与网页聊天可用之后再接；美化最后 | 前端测试全绿；真实对话走网关 | 待开始 |
| E | 管理后台：模型中心、密钥中心、用量/成本仪表盘、请求诊断、系统设置 | 各页功能真实可用 | 待开始 |
| F | 安全与备份：§8 全项 + 备份恢复真实演练 | 演练记录有证据 | 待开始 |
| G | 集成测试：接口/前端/Codex/异常/回滚 + Mock 与真实两套；IPA 评估文档（结论如实记录）；版本信息接口与设备同步冲突合并测试；CI（GitHub Actions 出包 + 服务端镜像）验证 | 测试报告真实命令与退出码 | 待开始 |
| H | 独立服务器部署（Spark 面板服务器）+ 在线更新/回滚演练 | 健康检查通过；门禁见架构 §10 | 门禁未满足（等 SSH 访问确认） |

规则：每阶段跑测试、提交 Git、记录 commit + 测试结果 + 未解决问题；
测试失败不得跳过进入下一阶段；不得伪造任何验证结果。
